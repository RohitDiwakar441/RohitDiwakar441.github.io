# Rohit Diwakar — Portfolio Website

A responsive dark-themed portfolio for GitHub Pages.

## Files
- `index.html` — page structure and resume content
- `style.css` — responsive visual design
- `script.js` — mobile navigation and footer year
- `assets/Rohit_Diwakar_Resume.pdf` — downloadable resume

## Publish to GitHub Pages
1. Extract this ZIP.
2. Open your repository: `https://github.com/RohitDiwakar441/RohitDiwakar441.github.io`
3. Upload `index.html`, `style.css`, `script.js`, and the `assets` folder to the repository root. Keep the existing `CNAME` file containing `rohitdiwakar.me`.
4. Commit the changes to the `main` branch.
5. In Settings → Pages, confirm publishing from `main` and `/(root)`.
6. Visit `https://rohitdiwakar.me`.

## Before publishing
- Confirm the resume contact details and project descriptions are current.
- Replace generic project GitHub links with each project's specific repository URL once available.
- The resume PDF was recreated from the supplied DOCX content for easy download. Review it before publishing.
- This is a static site; no backend or paid hosting is required.

## Customize
Edit `index.html` for content and `style.css` for colors/layout. No build tools are required.
